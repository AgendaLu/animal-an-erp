# Animal-AN 進銷存系統 — 使用手冊

> 給日常操作人員的說明書,不需要任何電腦專業知識。
> 系統完全離線運作,所有資料只存在你自己的電腦裡,不會上傳到網路。

---

## 1. 啟動與關閉

### 啟動系統
1. 打開系統資料夾 `animal-an-erp`。
2. 雙擊 **animal-an-erp**(Windows 上是 `animal-an-erp.exe`)。
3. 會出現一個黑色文字視窗(這代表系統正在運作,**請不要關掉它**),幾秒後瀏覽器會自動打開系統畫面。

> 瀏覽器沒有自動打開?自己開瀏覽器,在網址列輸入 `127.0.0.1:8000` 按 Enter 即可。

### 關閉系統
關閉那個黑色文字視窗,系統就停止了。已輸入的資料都已存檔,下次開啟會全部還在。

### 重複開啟
不小心點了兩次也沒關係 — 系統會發現已經在執行,只會再開一個瀏覽器頁面,不會弄壞資料。

## 2. 第一次使用:建立基礎資料

第一次使用時,請**依照這個順序**把基本資料建好(之後就很少需要動了):

| 順序 | 頁面 | 要建什麼 | 例子 |
|---|---|---|---|
| 1 | **供應商** | 向誰進貨 | 原廠A |
| 2 | **原物料** | 進貨的原裝品(整桶/整箱) | 維A原裝桶,單位「桶」 |
| 3 | **產品** | 賣給客戶的分裝品(SKU) | 維A 100ml,單位「瓶」,填「每 1 原裝分裝數」= 一桶可以分成幾瓶 |
| 4 | **客戶** | 賣給誰 | 永春牧場(可填信用額度) |

小提醒:
- 打「\*」的欄位是必填。
- 「代號 / 料號」建議用固定規則編(例如 SUP-001、BULK-001、PROD-001),之後找資料快很多。
- 建錯了?點表格裡那一列,上方表單會帶入內容,改完按「儲存修改」。

## 3. 日常作業流程

進出貨的順序永遠是:**進貨(整桶)→ 分裝(變成瓶)→ 銷貨(賣瓶)**。

### 3.1 進貨(建立進貨單)
「建立進貨單」頁面,填:
- 供應商、原物料
- **批號**:自己編的進貨批號(例如 B-20260701)
- 數量、**單位成本**(這批每桶多少錢)
- **效期**:必填!系統靠它提醒快過期的貨

按「建立進貨單」,庫存馬上增加。

### 3.2 分裝(原裝 → 零售包裝)
「庫存/分裝」頁面上方「分裝作業」:
1. 選要拆的**原裝批號**(括號裡會顯示現在還剩幾桶)
2. 選分裝成哪個**產品**
3. 填耗用幾桶、**產出批號**(自己編,例如 P-20260701)、產出效期
4. 按「執行分裝」

系統會自動算出產出幾瓶(桶數 × 每桶分裝數),成本也會自動分攤到每一瓶。

### 3.3 銷貨(建立銷貨單)
「建立銷貨單」頁面,選客戶、產品、數量;售價會自動帶產品的標準售價,可以改。

出貨時系統**自動先出最快到期的批號**(先到期先出),不用自己挑。
如果庫存不夠,整張單會被擋下來,不會出一半。

### 3.4 盤點調整
實際數量跟系統對不上時(破損、遺失、盤盈),用「庫存/分裝」頁的「庫存調整」:
- 盤盈填正數(例如 +2),盤虧填負數(例如 -3)
- **原因**必填,之後查帳才知道為什麼

## 4. 儀表板(首頁)

打開系統第一眼看到的就是儀表板:
- **庫存金額**:原裝、分裝、總額三張卡片
- **低庫存告警**(紅字):現量已經低於安全庫存的原物料 → 該叫貨了
- **近效期批號**:90 天內到期的貨 → 優先出掉

## 5. 報表

「報表」頁面有 8 種報表,每種都有「**匯出 CSV**」按鈕 — 按了會下載一個檔案,用 Excel 直接打開就能加工、列印、交給會計。

| 報表 | 什麼時候用 | 內容 |
|---|---|---|
| **進銷存月報** | 每月結帳 | 每個產品這個月的期初、進貨(分裝產出)、銷貨、期末(數量+金額) |
| **庫存即時表** | 隨時 | 每個產品現在有多少、值多少錢、有沒有快過期、要不要補貨 |
| **銷售毛利** | 檢討生意 | 每個客戶買了哪些產品、賺多少、毛利率 |
| **分裝產出** | 核對分裝 | 每次分裝耗了幾桶、產出幾瓶、有沒有差異 |
| **應收/信用** | 催收帳款 | 哪些客戶還欠錢、欠多久、**有沒有超過信用額度(紅字警告)** |
| **應付帳款** | 安排付款 | 該付供應商的錢和到期日 |
| **稅務彙總** | 報稅(雙月) | 銷項稅、進項稅、應納稅額;可「存為申報草稿」留底 |
| **日銷售** | 每日對帳 | 當天每張發票的金額與毛利 |

> 「應收/應付/稅務/日銷售」四種報表的資料來自會計發票。發票資料目前由匯入或 API 建立,尚未有輸入畫面 — 還沒使用會計功能的話,這幾張報表是空的,是正常現象。

## 6. 資料備份(很重要!)

所有資料都在系統資料夾裡的 **`data/animal_an.db`** 這一個檔案。

### 平常備份(最簡單的方法)
1. 關閉系統(關掉黑色視窗)
2. 複製整個 `data` 資料夾到隨身碟或其他硬碟
3. 建議:**每週至少一次**,月底結帳後一定要備一次

### 還原
把備份的 `data` 資料夾複製回系統資料夾蓋掉,再啟動系統。

### 換新電腦
把整個系統資料夾複製過去就好 — 程式跟資料都在裡面,不用安裝任何東西。

### 系統更新
拿到新版程式時:**整個資料夾換新,只把舊的 `data` 資料夾複製回來**。

## 7. 常見問題

**Q:雙擊後瀏覽器沒反應?**
黑色視窗有開著的話,自己開瀏覽器輸入 `127.0.0.1:8000`。黑色視窗一閃就消失,請聯絡系統管理員。

**Q:銷貨時說「Insufficient stock / 庫存不足」?**
分裝品不夠賣。先去「庫存/分裝」確認產品批號庫存,不夠就先分裝。

**Q:進貨單按了沒反應或變紅字?**
看紅字訊息 — 最常見是漏填效期或單位成本,補上就好。

**Q:資料會不會被別人看到?會上傳雲端嗎?**
不會。系統完全離線,只在這台電腦運作,資料只存在 `data` 資料夾。

**Q:數字打錯已經送出了怎麼辦?**
庫存數量錯誤用「庫存調整」修正並註明原因;主檔(供應商/產品/客戶)資料點該列直接改。

**Q:黑色視窗可以縮小嗎?**
可以,縮小不影響。只是**不要按到關閉**,關了系統就停了。

## 8. 名詞小字典

| 名詞 | 意思 |
|---|---|
| 原物料 / 原裝品 | 從供應商進來的大包裝(整桶、整箱、整棧板) |
| 產品 / 分裝品 / SKU | 拆成賣給客戶的小包裝(瓶、支、包) |
| 批號 | 每一批貨的編號,用來追效期跟成本 |
| 效期 | 有效期限;系統會自動先賣快到期的 |
| 先到期先出(FEFO) | 出貨時自動先出最接近到期日的批號 |
| 安全庫存 / 再訂購點 | 低於這個量,系統就提醒該補貨 |
| 批次成本 | 那一批進貨的單價;分裝後自動分攤到每瓶 |
| 信用額度 | 允許客戶最多欠多少錢;超過會在報表紅字警告 |
| 應收 / 應付 | 客戶還沒付你的錢 / 你還沒付供應商的錢 |
