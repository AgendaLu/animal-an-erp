## 10. 單據（沿用既有結構）

[models/order.py](../models/order.py)、[models/payment.py](../models/payment.py)：

- **PurchaseOrder / PurchaseOrderItem** — 進貨單頭（po_number `POyyyymmdd-NNN`、supplier_id、order_date、total_amount、status、payment_status）與明細。
- **SalesOrder / SalesOrderItem** — 銷貨單頭（so_number `SOyyyymmdd-NNN`、customer_id、total_amount）與明細；明細含 `batch_id`（FEFO 分配批號）、`unit_price`（預帶標準售價可覆寫）、`total_price`、`shipped_quantity`。
- **Payment** — 收付款（reference_type PO/SO、amount、payment_method、status）。
